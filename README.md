# GUN MERGE 3D

コンピュータと対戦するシングルプレイの 3D ブラウザゲーム（Three.js / WebGL）。
Android・iPhone・iPad のブラウザ（Chrome / Safari）向け。外部ビルド不要の静的ファイル構成です。

## 遊び方
1. タイトル →「タップしてスタート」→ ホーム（保持している銃・コインを確認、コインで銃を追加）
2. 「ゲームスタート」で配置画面へ。下の一覧から銃を選び、自陣（青）のマスをタップして配置
   - 同じ **ランク** の銃を同じマスに重ねると合体（レベル = 合計、最大 Lv.1000）
   - 配置済みの銃はドラッグ／タップで移動、ランク違いは入れ替え
3. 「スタート」でバトル。砲塔が敵へ回転し、照準が合うと反動＋マズルフラッシュで射撃
   - 味方の弾は味方をすり抜け、ダメージを与えません
   - HP が 0 になると爆発して消滅。どちらかが全滅で終了
4. 勝利: 多めのコイン＋次のステージ / 敗北: 少しのコイン＋リトライ。ステージが進むほど敵が増え強くなります
5. **自動連戦**: 配置画面の「自動連戦」を ON にしてスタートすると、勝利後 3 秒のカウントダウンで同じ配置のまま次のステージが自動で始まり、負けるまで続きます
   - バトル中や勝利画面の「自動連戦を止める」でいつでも停止できます（設定は保存されます）
   - 敗北すると停止し、「自動連戦終了：N連勝」を表示します

ランク: C(1-9) / B(10-49) / A(50-149) / S(150-349) / SS(350-699) / SSS(700-999) / MAX(1000)

**銃口の数 = レベル ÷ 100 の商 + 1**（Lv.1〜99: 1、Lv.100〜199: 2 … Lv.1000: 11）。
1回の攻撃で銃口の数だけ弾丸を同時に発射し、銃口は放射状（扇形）に並んでいます。
レベルが上がるほど扇の角度が広がり（Lv.100: 約14° → Lv.1000: 約149°）、広い範囲に弾をばらまきます。
中央の銃口が狙った敵を向き、外側の弾はその周りの敵に当たります。弾1発のダメージ = 攻撃力 × 2 ÷ (銃口数 + 1)。

| ランク | 弾丸の形 |
|---|---|
| C | 小さな弾（キューブ） |
| B | 細長い弾丸 |
| A | エネルギー球 |
| S | 回転するクリスタル |
| SS | ミサイル |
| SSS | 光るプラズマ弾（尾つき） |
| MAX | 回転する金の星 |

弾丸の大きさはレベルが上がるほど大きくなります。

対応言語: 日本語・English・简体中文・한국어・Español（ブラウザ言語で自動判定、画面で切替可）

## 起動
```bash
npm install          # three と @playwright/test（テスト用）
npm start            # http://localhost:8080/
```
スマホ実機では同じ LAN から `http://<PCのIP>:8080/` を開いてください。
`?speed=4` を付けるとバトルを早送りできます（デバッグ用）。

## PWA
- ホーム画面に追加すると、全画面のアプリとして起動します（Android: ホーム画面の「アプリとしてインストール」ボタン / iPhone・iPad: Safari の共有 →「ホーム画面に追加」）。
- Service Worker（`sw.js`）がゲームのファイルをキャッシュするので、一度開けばオフラインでも遊べます。
- アイコンは `node tools/gen_icons.mjs` でドット絵から生成しています（`icons/`）。

## GitHub Pages への公開
`main` ブランチに push すると、`.github/workflows/pages.yml` が次の順に実行します。
1. Playwright で全テストを実行（失敗したら公開しない）
2. `node tools/build-site.mjs` で公開用の `_site/` を作成（Service Worker のキャッシュ名にコミット SHA を埋め込み、更新が確実に反映されるようにする）
3. GitHub Pages にデプロイ

リポジトリの Settings → Pages → Source が「GitHub Actions」になっている必要があります。

## テスト
```bash
npx playwright test
```
Android (Pixel 7 / Chromium)、iPhone 15 (WebKit)、iPad (WebKit) のエミュレーションで E2E テストを実行し、
`tests/rules.spec.js` でゲームロジック（合体・ダメージ・爆発・終了判定・報酬・難易度）を検証します。

## 構成
- `index.html`, `css/style.css` — UI（タイトル / ホーム / 配置 / バトル HUD / 勝敗オーバーレイ）
- `src/main.js` — 画面遷移・入力・セーブ
- `src/scene.js` — Three.js 描画（ボクセル風の銃、弾、爆発、カメラ自動調整）
- `src/battle.js` — 決定的なバトルシミュレーション
- `src/gunstats.js` — ランク・ステータス・合体・敵生成・報酬
- `src/i18n.js` — 多言語文字列
- `assets/` — ドット絵（Codex が `tools/gen_pixel_art.mjs` で生成）
- `vendor/three.module.js` — Three.js r170
- `sw.js`, `manifest.webmanifest`, `src/pwa.js`, `icons/` — PWA
- `tools/build-site.mjs`, `.github/workflows/pages.yml` — GitHub Pages 公開
