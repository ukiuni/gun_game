# GUN MERGE 3D

コンピュータと対戦するシングルプレイの 3D ブラウザゲーム（Three.js / WebGL）。
Android・iPhone・iPad のブラウザ（Chrome / Safari）向け。外部ビルド不要の静的ファイル構成です。

## 遊び方
1. タイトル →「タップしてスタート」→ ホーム（保持している銃・コインを確認、コインで銃を追加）
2. 「ゲームスタート」で配置画面へ。下の一覧から銃を選び、自陣（青）のマスをタップして配置
   - 同じ **ランク** の銃を同じマスに重ねると合体（レベル = 合計、最大 Lv.1000）
   - 配置済みの銃はドラッグ／タップで移動、ランク違いは入れ替え
3. 「スタート」でバトル。砲塔が敵へ回転し、照準が合うと反動＋マズルフラッシュで射撃
   - 味方の弾は味方をすり抜け、ダメージを与えません
   - HP が 0 になると爆発して消滅。どちらかが全滅で終了
4. 勝利: 多めのコイン＋次のステージ / 敗北: 少しのコイン＋リトライ。ステージが進むほど敵が増え強くなります

ランク: C(1-9) / B(10-49) / A(50-149) / S(150-349) / SS(350-699) / SSS(700-999) / MAX(1000)

| ランク | 砲身 = 1回の発射弾数 | 弾丸の形 |
|---|---|---|
| C | 1 | 小さな弾（キューブ） |
| B | 1 | 細長い弾丸 |
| A | 2 | エネルギー球 |
| S | 2 | 回転するクリスタル |
| SS | 3 | ミサイル |
| SSS | 3 | 光るプラズマ弾（尾つき） |
| MAX | 4 | 回転する金の星 |

弾丸の大きさはレベルが上がるほど大きくなります。1回の攻撃の総ダメージ（攻撃力）は弾数で等分されます。

対応言語: 日本語・English・简体中文・한국어・Español（ブラウザ言語で自動判定、画面で切替可）

## 起動
```bash
npm install          # three と @playwright/test（テスト用）
npm start            # http://localhost:8080/
```
スマホ実機では同じ LAN から `http://<PCのIP>:8080/` を開いてください。
`?speed=4` を付けるとバトルを早送りできます（デバッグ用）。

## テスト
```bash
npx playwright test
```
Android (Pixel 7 / Chromium)、iPhone 15 (WebKit)、iPad (WebKit) のエミュレーションで E2E テストを実行し、
`tests/rules.spec.js` でゲームロジック（合体・ダメージ・爆発・終了判定・報酬・難易度）を検証します。

## 構成
- `index.html`, `css/style.css` — UI（タイトル / ホーム / 配置 / バトル HUD / 勝敗オーバーレイ）
- `src/main.js` — 画面遷移・入力・セーブ
- `src/scene.js` — Three.js 描画（ボクセル風の銃、弾、爆発、カメラ自動調整）
- `src/battle.js` — 決定的なバトルシミュレーション
- `src/gunstats.js` — ランク・ステータス・合体・敵生成・報酬
- `src/i18n.js` — 多言語文字列
- `assets/` — ドット絵（Codex が `tools/gen_pixel_art.mjs` で生成）
- `vendor/three.module.js` — Three.js r170
